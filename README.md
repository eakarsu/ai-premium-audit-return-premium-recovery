# Premium Audit Return-Premium Recovery

Recalculate final premium audits and recover overcharges caused by classifications, exposures, uninsured subcontractors, or missing credits.

**Primary buyer:** Commercial policyholders and brokers. **Evidence:** policies, classifications, payroll, sales, subcontractor costs, certificates, audit worksheets, endorsements, invoices, and refunds.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Policy exposure terms
- Classification code library
- Payroll exposure ingestion
- Sales exposure ingestion
- Subcontractor cost review
- Certificate validation
- Owner officer exclusion
- Experience modification control
- Rate and factor calculation
- Audit worksheet reconstruction
- Dispute evidence package
- Carrier negotiation workflow
- Return premium calculation
- Refund reconciliation
- Policy class analytics

Run `./start.sh`, then open <http://127.0.0.1:4664>. API: `5664`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
